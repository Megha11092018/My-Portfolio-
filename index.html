Project One - Automated Food Recognition and Calorie Estimation

Developed a web application for food detection and calorie estimation from images using Deep Learning

Technologies: Deep Learning with Python, Keras, Mobilenet

Featured

This project is a web application that utilizes deep learning techniques to recognize food items from images and estimate their calorie content. The application is built using Python and Keras, leveraging the Mobilenet architecture for efficient image classification. Users can upload images of their meals, and the system will analyze the food items present, providing an estimated calorie count based on the recognized items. This project demonstrates my ability to apply machine learning concepts to real-world problems and create user-friendly applications.

Project Two - CARDIORET-Cardiovascular Risk Prediction using Retinal Eye Images

Designed a heart attack risk prediction model using retinal images by integrating Recurrent Neural Networks (RNN)with AdaBoost. The system enhances accuracy in early cardiovascular risk detection Through deep learning and ensemble techniques

web technologies: HTML, CSS, Javascript for frontend
Backend technologies: python, clustering model, keras, tensorflow.
Framework: Flask

New

This project focuses on developing a cardiovascular risk prediction model using retinal eye images. By integrating Recurrent Neural Networks (RNN) with the AdaBoost algorithm, the system aims to enhance the accuracy of early cardiovascular risk detection. The application is built using a combination of frontend technologies (HTML, CSS, JavaScript) and backend technologies (Python, clustering models, Keras, TensorFlow) with Flask as the framework. Users can upload retinal images, and the model will analyze them to predict the risk of cardiovascular events, providing valuable insights for preventive healthcare.
